# Brahmaputra Bites — Taste of Assam

A responsive food ordering website prototype inspired by Assamese cuisine. Built as a Summer Project demonstration using HTML, CSS and vanilla JavaScript.

## Features
- Responsive landing page and food menu
- Search dishes by name or description
- Filter by food category
- Add items to cart and update quantities
- Automatic subtotal, delivery fee and total calculation
- Cart persistence using browser localStorage
- Demo checkout form with validation and order confirmation
- Mobile-friendly layout

## Tech stack
- HTML5
- CSS3
- JavaScript (ES6)
- Browser localStorage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add dishes to your cart and test the demo checkout.

No build tools or package installation are required.

## Important project scope
This is a frontend prototype. Checkout is simulated: it does not connect to a restaurant, server, database, payment gateway or delivery service. Menu photos are loaded from Unsplash and therefore require an internet connection.
